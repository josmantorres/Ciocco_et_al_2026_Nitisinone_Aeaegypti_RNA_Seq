The quality of raw sequencing reads was assessed using FastQC software (Ward et al., 2020). Low-quality reads and adapter sequences were filtered using Trimmomatic (v0.39) (Bolger et al., 2014) in paired-end mode, with the parameters TRAILING and LEADING = 5 and SLIDING-WINDOW set at 4:15. Adapter trimming was performed using ILLUMINA-CLIP (2:30:10). Reads shorter than 50 bp were discarded. STAR software (v2.7.10b) (Dobin et al., 2013) was used to index the Ae. aegypti reference genome along with its annotation in gtf format, converted from the gff (downloaded from VectorBase, v67, AaegyptiLVP_AGWG) file using the gffread tool. The reads were mapped and counted using the GeneCounts function in STAR with default parameters, except –outFilterMultimapNmax, which was set to 1
